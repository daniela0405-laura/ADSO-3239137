# page — Sitio público estático

Presenta el producto Camping Rental: qué es, para quién es y qué hace (tarea T-23).

- HTML y CSS puros, **sin llamadas a la API** y sin dependencias externas.
- Diseño *mobile first*: se adapta a celular, tableta y escritorio.
- Textos en español; clases CSS en inglés (artículo XI de la constitución).

## Cómo verlo

Abrir `index.html` en el navegador (doble clic). No necesita servidor.

## Archivos

| Archivo | Contenido |
|---|---|
| `index.html` | Secciones: inicio, qué es, funciones, cómo funciona y reglas |
| `styles.css` | Estilos y puntos de quiebre para 700 px y 1000 px |
